# 极客兔（jiketu）

「**极客兔**」面向创作者与学习者，聚合 **稀缺数字资源**、**技能与实践经验**、**实用在线工具**，并配套 **个人博客** 与 **社区交流**，提供可持续浏览与沉淀的高质量内容。

- **📂绝版 / 数字资源**：精选与整理，便于获取与复用
- **💻技能与经验**：可落地的方法与案例
- **🔧在线工具**：日常开发、学习、办公向小工具
- **📝博客与社区**：个人长文、讨论与「天涯社区」等互动内容

本仓库为 **pnpm monorepo**，官网与文档站由 `apps/web`（VitePress + Vue）构建。

## 本地开发

```bash
pnpm install
pnpm dev
```

🔨 **生产构建**：

```bash
pnpm build
```
