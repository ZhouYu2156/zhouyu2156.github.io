社会乱象背后的本质是什么

不管关不关注时事的人，最近几年或多或少应该都了解缅甸诈骗、翟欣欣案、红衣大姐、穿吊牌衣七天退货、崩老头等这些社会现象。

从这各种社会乱象来看，没有人是吃饱了撑的，去做一些于人于己都没意义的事情，而做了，那必定是要对自己有利的。

正所谓“人为财死鸟为食亡”，这一切背后的原因都是钱！

以前的缅甸园区，就利用很多人追求轻松月入过万的心理实施诈骗，要么把你骗到缅甸嘎腰子贩卖器官，要么把你关起来当狗使，当然进去后连狗都不如。

经过国家十多二十年的大力科普，缅甸诈骗的历史经验才深入人心，让每个人都提高了警惕，所以高薪返利这种老掉牙的诈骗方式，在如今是很难再有人相信。

接着到翟欣欣时代，社会普遍面临的问题是圈子窄难找对象的课题，那么此时就兴起了婚恋相亲网站。

这些网站最大的服务群体一般是有点钱，但没闲暇时间在现实中找对象的有钱人，对于这类群体，网站会推出几百到几千块钱的会员套餐。只要他们开通会员，就会获得高级的身份标识，从而吸引优质女的搭讪，提升选择优质伴侣的机会。

翟欣欣这类女人就抓住了这样的机会，凭借自己硕士高学历的身份，漂亮的外表以及高挑的身材，以及对人性和心理的精准把控，把上千万资产的苏享茂玩得团团转。

人心不足蛇吞象，她胃口太大，以至于把事情逼到无法把控的地步。苏享茂最后也只能用跳楼的方式将一切真相公之于众，誓与翟欣欣同归于尽。

现在市面上还有很多婚恋网站和相亲软件，你注册账号，系统了解到你的性别后，一堆的异性给你发消息，对你说各种调情的话，这时候，估计很多男人都会被迷得神魂颠倒，感觉自己上了天堂一样。

等你跟她们聊了几句后，系统马上会提示你要开会员才能继续聊天。

这时候你应该懂了吧？就是让你充钱啊！

那我说得再直白一点，你屏幕对面跟你聊天的，究竟是不是个人，或者说，是不是个异性都是个谜，但你还为对方的文字感动不已，属实可笑。

这些婚恋软件就是利用很多现代人沉迷手机，想在手机上就能找到对象的心理对症下药，给你们制造暧昧，让你们在软件上充钱，可能背后是几十个抠脚大汉在运营。他们利用变声器和内部女主播与你们进行语音、视频互动，让你们感觉她们是真实的。

几年前我在长沙应聘过一家网红公司，他们内部就是这么干的！公司实行倒班，晚上会在探探、陌陌等一些软件上开播，说是聊天主播，但实际上有才艺的也可以表演才艺活跃氛围。很多人打赏女主播一晚，至少够她吃一个月了。
